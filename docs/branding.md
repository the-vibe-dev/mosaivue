# Mosaivue brand assets

The supplied artwork is the source for the beta identity. The app uses the horizontal wordmark in navigation and setup, and the supplied camera-wall symbol as its favicon.

| Asset | Use |
|---|---|
| [mosaivue-logo.png](../frontend/src/brand/mosaivue-logo.png) | Dashboard and setup wordmark |
| [mosaivue-icon.png](../frontend/src/brand/mosaivue-icon.png) | Browser and installed-app icon |
| [mosaivue-stacked.png](../frontend/src/brand/mosaivue-stacked.png) | Documentation and release artwork |

The frontend build copies these exact supplied PNGs into the runtime static assets. Their white backgrounds suit the default light interface; dark mode presents the logo on a white surface.
